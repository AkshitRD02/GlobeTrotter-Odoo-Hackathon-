# 🌍 GlobeTrotter

### ✈️ Empowering Personalized Travel Planning

> **Plan smarter. Travel better. Explore more.**

GlobeTrotter is a personalized travel-planning platform designed to make organizing multi-city journeys simple, interactive, and enjoyable.

From discovering destinations and building detailed itineraries to tracking budgets and sharing trips with the community, GlobeTrotter brings the entire travel-planning experience into one place.

🔗 **Live Demo:** https://glistening-horse-cec2f3.netlify.app/

---

## ✨ Features

### 🔐 Authentication
- User registration and login
- Personalized user accounts
- Profile management
- Password-based authentication
- Account settings and preferences

### 🗺️ Multi-City Trip Planning
Create complete trips with multiple destinations and travel stops.

- Create and manage trips
- Set trip start and end dates
- Define a total budget
- Add trip descriptions
- Select cover images
- Add multiple destinations
- Set arrival and departure dates

### 📅 Interactive Itinerary Builder

Build your trip day-by-day with an interactive itinerary.

- Add travel stops
- Add activities to each destination
- Schedule activities by date and time
- Categorize activities
- Estimate activity costs
- Timeline-based itinerary view
- Stop overview

### 💰 Smart Budget Tracking

Keep your travel expenses under control with built-in budget analysis.

The platform provides breakdowns for:

- 🚗 Transportation
- 🏨 Accommodation
- 🎯 Activities
- 🍴 Meals
- 💵 Total estimated cost
- 📊 Budget utilization

### 🔎 Destination Discovery

Explore destinations around the world and discover useful travel information.

- Search cities
- Search countries
- Search landmarks
- Explore destination information
- View cost indexes
- Discover sightseeing locations
- Explore popular activities

### 📆 Travel Calendar

Visualize all your planned journeys in a calendar.

The calendar helps users:

- View upcoming trips
- Understand trip durations
- Identify overlapping schedules
- Organize travel plans chronologically

### 🌎 Travel Community

Discover travel plans created by other users.

- Browse public itineraries
- Explore shared trips
- View trip budgets and durations
- See destinations included in public trips
- Copy interesting itineraries into your own plans

### 👤 User Profile

Manage your personal travel preferences from one place.

- Update profile information
- Change profile picture
- Set preferred language
- Set preferred currency
- Save destinations
- Manage account settings

### 📊 Admin Dashboard

Administrators can monitor the platform and analyze user activity.

- Manage users
- Monitor popular cities
- Track popular activities
- View user trends
- Analyze engagement
- Search users, destinations, and activities

## 🎯 Why GlobeTrotter?

Planning a trip often requires switching between multiple applications for:

- Destination research
- Itinerary management
- Budget calculations
- Scheduling
- Travel inspiration
- Sharing plans

**GlobeTrotter brings these workflows together into a single travel-planning experience.**

Instead of simply finding destinations, users can go from:

**Discover → Plan → Schedule → Budget → Organize → Share**
